# 生活服务本机策略核对

2026-11-07，核对798、胖乖及共用扫码、进度、付款入口。设备是否允许使用，以本次服务端响应为准；本机历史进度、手机时间及缺失字段不提供业务拒绝的依据。

## 已移除或修正的限制

| 行为 | 原实现 | 本次处理 |
| --- | --- | --- |
| 退出账户 | 本机有活动或结果未知进度就拒绝退出 | 退出不检查服务状态，停止本机处理并清理所选平台凭据及进度 |
| 更换账户 | 本机有活动进度就拒绝换号 | 去掉服务状态检查，只在请求提交或凭据写入期间避免并发替换 |
| × 移除异常进度 | 无订单号的未知下单记录只标记隐藏，继续持久保存 | 删除指定进度及本机记录；登录失效后也可删除；恢复时清理旧版本已隐藏记录 |
| 同设备重新下单 | 无订单号的历史未知记录永久拦截同设备新订单 | 去掉该拦截，重新扫码后由用户明确发起新订单 |
| 798多设备使用 | 任意本机活动进度拒绝另一台设备 | 查询本次目标设备，空闲时可发启动请求，平台决定是否接受 |
| 798未知进度 | 旧记录劫持扫码，Starting遇空闲也无法移除 | 先查设备再核对旧记录；无标记的未知进度可 × 删除或重新扫码，空闲时释放跟踪 |
| 798绑定归属 | 必须有启动应答、服务器时间与本机尝试相差60秒内 | 丢应答核对主页使用人及运行标记，不按本机时间认定归属 |
| 798恢复门槛 | 启动前要求本机已有uid且整账号恢复结束 | 不阻止目标设备启动；核对未知运行归属时才读账号ID，缺favos不阻有效ID |
| 798结束入口 | 不在本机确认集合就禁用结束按钮 | 保留运行阶段结束入口，点击后核对使用人和运行标记，暂未同步可重查 |
| 胖乖水异常 | 明确拒单或丢响应留下不可移除的无号活动记录 | 明确拒单清理；丢响应标记未知，提供 × 和重新扫码，不自动重发启动 |
| 淋浴故障 | status=6仍停在普通活动阶段 | 显示设备异常，可移除或重新扫码，不标完成、不创建后付订单 |
| 洗衣付款期限 | 本机五分钟阻止续付和SDK认领 | 仅展示参考倒计时，服务端决定付款许可及关闭状态 |
| 广告优惠字段 | 成功预览返回promotions.isUsed就拒绝 | 继续使用空优惠请求，不按广告字段自行拒绝 |
| 订单金额变化 | 价格不同阻断状态读取、恢复及取消 | 采用最新金额；查询和取消继续，真正付款前金额变化要求再次确认 |
| 缺失能力字段 | 默认不可用、需蓝牙或未开通 | 保存并展示未知，仅明确false/true构成对应限制 |
| 旧扫码配置 | 旧错误和能力持续挡操作，活动设备不能刷新 | 开始或报价前读新配置，活动设备可刷新，结束前读取最新结束能力 |
| 关闭与退款 | 本机已付或运行压过服务端关闭 | 状态1关闭、4退款中、5已退款；不由本机旧阶段覆盖 |

×只删除本机跟踪，不调用平台取消、结束或解约。正常已有订单可进入详情处理的进度不增加异常 ×。删除后迟到响应不能恢复记录；恢复读取也不能覆盖期间新发出的设备命令。已取得订单号的待付款订单仍从原订单继续付款。

## 保留的核对和等待策略

| 行为 | 当前实现 | 依据与覆盖范围 |
| --- | --- | --- |
| SDK等待期限 | 支付宝未进入付款页面等待15秒；返回桥接页后给回调1秒；银联也有15秒唤起等待 | 为修复SDK无回调导致界面无法操作而加入；具体期限为项目选择，未证明官方使用相同值 |
| 查询次数与设备等待上限 | 支付结果最多3次、间隔5秒；胖乖用水等待20次、间隔1.5秒；洗衣启动等待30次、间隔1秒；798等待10次、间隔3秒 | 次数和上限是项目策略。洗衣设备检查40次、间隔500毫秒已另按官方流程核对；其他上限不宣称与官方相同 |
| 账户核验缓存 | 成功结果复用5分钟；自动失败重试冷却30秒；手动刷新绕过缓存 | 项目缓存策略，未核定官方使用相同期限 |
| 冷启动进度恢复 | 保留查询失败的已知进度供再次核对；无号未知记录可移除；明确结束或其他归属才移除旧跟踪 | 不因请求失败推断完成，不自动重放设备或付款命令 |

本次服务端明确业务拒绝、健康=false、渠道不可用/需开通、设备运行中、订单关闭等按响应处理。账号、设备、程序、订单与798运行标记用于结果归属；明确不匹配不操作他人的设备。主页与状态暂未同步不宣称平台拒绝结束，保留刷新和结束核对入口。请求提交互斥、SDK请求ID认领、迟到结果隔离继续保留，不按活动记录总数拒绝操作。

等待上限只结束当前等待，不证明拒单、支付失败、设备完成或订单关闭。账户缓存、短信倒计时、输入校验、已知离线提示为客户端请求和展示策略；不提供设备许可结论。洗衣完成提醒到完成日期次日北京时间03:00，为用户指定展示期限。
