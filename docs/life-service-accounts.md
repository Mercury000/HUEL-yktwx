# 生活服务账户

付款页保持付款码为核心，继续使用原有胖乖与798轻提醒。原来的右侧箭头直接换成关闭按钮，整条提醒只有一层背景，其余区域仍可点击登录。关闭后 Toast 提示「可在设置 → 生活服务账户中登录」。两平台的关闭选择分别持久保存，关闭不退出账号，也不影响设备页要求登录时的提示。

## 设置与页面

- 设置直接按「生活服务账户、通用、应用更新」分组，分组标题直接使用 demo 的 SmallTitle 默认颜色、subtitle 字体样式与内部间距。生活服务账户与其他设置项使用相同的 Miuix 默认 Card 和 ArrowPreference，不指定不同圆角。
- 第一张设置卡直接放慧生活798和胖乖生活两个偏好项，各自显示脱敏手机号（未登录时显示服务范围）和状态。不设置独立账户列表、详情页、顶栏全部检查或额外管理按钮。
- 点击未登录或登录失效账户直接打开现有登录抽屉；点击已保存且未失效的账户直接打开 Miuix 退出确认弹窗。标题为「退出{平台名}账户」，一句「退出后需重新登录。」，仅取消、退出两个按钮，不重复手机号或放其他管理操作。退出后仍停留设置页；退出失败时用错误文案替换说明，允许重试。
- 设置下拉刷新核验已保存、未失效的平台；自动检查不占用下拉刷新指示器。
- 有进行中服务时，弹窗显示「暂时无法退出」「服务结束后才能退出账户。」，仅取消、查看进度两个按钮；失效时仍可重新登录原账号。复用 ArrowPreference、LifeAccountLoginSheet、原生验证码输入、OverlayDialog、DashboardPullToRefresh 和既有服务进度入口。
- 登录与设备恢复结果分别显示。798主页核验成功后即为已登录，个别设备恢复失败不改变账号状态。

## 状态与账号隔离

- 状态为未登录、检查中、已登录、待验证、登录失效。记录本次成功确认时间。
- 启动后、返回前台及进入相关页面核验账号。同一成功结果复用5分钟，失败自动读取冷却30秒；下拉刷新绕过缓存，同平台合并并发检查。
- 网络、超时及数据不完整保留凭据并显示待验证；明确鉴权失效清除不可用凭据，保留脱敏手机号和原账号服务恢复记录。后台核验不会自动弹出登录抽屉。
- 换号成功后替换凭据；请求取消和旧凭据的迟到核验响应不能覆盖新账号。写入新凭据失败时保留旧账号和记录。
- 有进行中用水、洗衣、待付款或启停待确认服务时阻止退出，允许重新登录原账号。重新登录表单即使输入其他号码，也会在替换前再次检查。
- 移除只清理所选平台的本机凭据及记录，不注销平台账号、不解除免密、不影响另一平台或校园卡。校园卡退出文字明确其范围。
