# 界面图标

业务图标集中在 `AppIcons`，校园卡管理、大厅、设备页和生活服务进度胶囊复用同一套图形。以实际图形外缘校准视觉大小，不能仅比较图标控件的宽高。

- 基础操作优先采用当前 miuix 版本的官方 Regular 图形。校园卡、查询密码、设置、关于、关闭、完成、键盘、手电筒和校园网均保留官方路径，统一留白。日期下拉使用官方 `ChevronForward` 旋转 90°，不使用形状不同的 `ExpandMore`。
- 水、电、空调、洗衣、骑行、票据、卡片异常、代人充值和等待状态使用业务向量图标。轮廓统一圆角端点、圆角连接及 2.2 单位的基准线宽；实心图形的镂空透明，随图标整体着色，不画固定白色细节。
- 通常业务图形在 24 单位画布中最多占 18 单位。付款二维码较密，最多占 17 单位；关闭及下拉等紧凑操作图形最多占 16 单位。
- 校园卡管理、设置、关于和设备页共用 `ServiceIcon`：图形尺寸为底座的 60%，圆角半径为底座的 34.375%，使用 `DashboardPalette.iconPanel` / `iconAccent` 适配普通、深色及动态主题。
- 列表和详情页使用同一个图标源按场景缩放。进度胶囊继续保留环形进度所需的内留白；扫码按钮保持官方 Scan，付款及二维码消费记录使用付款二维码；所有导航样式的账单共用票据图标。
- 普通校园卡账户信息使用不带异常标记的官方卡片。带叉号的卡片仅用于付款码暂停等异常状态。成功、失败与等待的支付结果使用共用图形，状态颜色由原有页面决定。

新增或调整图标时，先检查小尺寸、深色和同组图形的视觉重量；图标名相近不代表实际图形或功能含义相同。
