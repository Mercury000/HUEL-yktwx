# 页面导航与转场

页面导航使用 `miuix-nav-android:0.9.4` 的 `NavDisplay`。主题设置中的“转场风格”提供与 demo 相同的 **Miuix / AOSP** 选择，默认 Miuix，选择后立即生效并保存在本机。

## Miuix

- 普通进入与返回使用库默认的 500ms 曲线。进入页从末端滑入整页宽度，被覆盖页向起始方向移动 ¼ 页宽，透明度最多降低 10%；RTL 布局镜像。
- 使用 demo 默认的前缘圆角裁剪和最大 0.5 调暗，圆角半径跟随设备屏幕；过渡期间不额外启用全局输入拦截。

## AOSP

使用 demo 的 `CrossActivityTransition`，仅调整 Kotlin 包名，保留原实现及 Apache-2.0 版权声明。

- 普通进入与返回使用 450ms 曲线，两层页面平移 96dp；进入页和退出页有独立的 83ms 淡入、淡出时间轨道，无缩放和调暗。
- 系统预测返回和页面滑动返回采用卡片缩放，最小约 90%，四角裁剪、纵向跟手和速度相关回弹均沿用 demo。取消恢复原位，确认后卡片飞出并淡出。
- 手势调暗强度为浅色 0.2、深色 0.8；缺少屏幕圆角或在宽屏区域内时使用 demo 的 32dp 备用圆角。

## 共用导航行为

- 系统预测返回由库处理，没有独立开关。Miuix 共用普通转场的页面变换；AOSP 通过 demo 的方向转场组合区分普通进出和手势返回。
- “启用滑动返回”沿用 demo 的可选页面滑动返回，默认关闭。它控制页面内的滑动手势，不关闭系统预测返回；方向随 LTR / RTL 布局变化。
- 宽屏侧栏位于 `NavDisplay` 外部，保持固定。右侧导航区域裁剪越界图层；Miuix 区域内转场不使用屏幕圆角，AOSP 使用备用圆角。

原有 `IslandNav`、三层限制、背景缩放和模糊、返回距离设置、独立底部导航升降动画已移除。旧预测返回设置不再读取。顶栏和底栏的模糊设置继续控制各自的背景。

页面栈由 `rememberNavBackStack<Screen>` 保存，路由只包含可序列化的页面枚举。重复打开同一个路由时不重复入栈。业务模型、账户信息和支付数据不写入导航状态。

登录边界也跟随所选风格，以单个路由替换展示当前登录状态。应用级服务模型继续由原来的 ViewModel owner 管理，退出期间仍按当前登录状态清除付款内容并禁用旧页面操作。
