# 生活服务

财小通在付款页提供统一的扫一扫入口，支持胖乖接水、淋浴、洗衣、慧生活798用水和哈啰单车。设备页面显示可用操作与当前状态，进行中的服务集中显示在付款页状态卡。

## 账号管理

在 **我的 → 应用设置 → 生活服务账户** 中登录或退出平台账号：

| 账号 | 服务 |
| --- | --- |
| 胖乖生活 | 接水、淋浴、洗衣 |
| 慧生活798 | 生活用水 |
| 哈啰单车 | 骑行、余额与骑行卡 |

各平台账号独立保存。扫码时尚未登录，可在设备页面完成登录，随后继续原设备查询。登录提醒可以分别关闭。

## 扫码与设备编号

打开付款页扫一扫，对准设备二维码即可进入对应服务。无法扫码时使用手动输入，填写设备编号；编号对应多个平台时选择实际设备所属平台。

扫描正在使用的设备会返回原服务进度。离开设备页后，可点击付款页状态卡继续操作；重新打开应用时自动读取当前账号的服务状态。

## 胖乖接水

1. 扫描饮水设备二维码，查看设备信息与出水口。
2. 选择出水口和可用支付渠道，放好容器后点击开始接水。
3. 接水期间查看设备状态与参考时间。
4. 接好后点击结束接水，页面显示设备的结束结果。

离开页面不会自动停止出水。费用和扣款明细可在胖乖生活或对应支付平台查看。

## 胖乖淋浴

扫描淋浴设备，选择出水口和支付宝免密渠道，点击开始淋浴。使用结束后点击结束淋浴，也可从付款页状态卡返回当前设备。

淋浴与接水共用胖乖账号，设备页分别显示对应的开始和结束操作。费用通过平台的后付订单结算。

## 胖乖洗衣

扫描洗衣设备后选择程序，查看服务时长与价格，再选择支付方式。支持平台提供的余额、支付宝和银联付款，桶自洁作为独立程序选择。

支付后设备页显示当前订单和洗衣进度。待支付订单可继续付款或取消，订单结果会在页面和付款页状态卡同步更新。

## 慧生活798用水

扫描798设备二维码，查看设备信息并点击开始用水。设备页显示运行状态与参考时间，使用结束后点击结束用水。

返回前台时自动刷新状态，重新打开应用时恢复账号当前使用的设备。再次扫描同一设备直接进入现有用水进度。签约、账号绑定、充值与费用明细在慧生活798中管理。

## 哈啰单车

### 骑行

扫描车辆二维码后查看车辆信息，按页面提示开锁。骑行中可进行临时锁车、继续骑行和还车；还车时根据平台提示处理位置与停车要求。

骑行状态保留在付款页，点击状态卡可返回车辆页面。临时锁车按平台骑行规则计费，可用期限显示在页面中。需要官方应用处理的操作提供跳转入口。

### 付款

还车后查看应付费用并选择付款方式，支持平台提供的余额、支付宝和普通银联付款。支付完成返回财小通后，应用自动查询原订单并更新结果。

### 余额与骑行卡

点击设置中的哈啰账号进入详情，查看余额、已有骑行卡、学生认证和校园商品。普通骑行卡可展开查看，支持购买及续费。卡片说明、价格和使用条件由平台提供。

## 服务状态与支付

设备操作和支付完成后，应用查询对应订单并更新状态。网络中断时保留原服务和订单，可返回页面继续查询。离开页面或关闭支付抽屉不会重复下单。

各平台凭据与进行中记录加密保存在本机，账号切换后显示对应账号的内容。接口配置见[开发说明](development.md)。
