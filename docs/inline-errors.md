# 内联错误反馈

内联错误统一使用共享的显示、隐藏动效。输入错误只在用户实际修改相关字段时清除；读取失败、会话失效和操作结果待确认不因输入而消失。

## 动效

- `AnimatedInlineError`：150 ms 淡入淡出，200 ms 从顶部展开和收起。
- `InlineErrorGroup`：把错误和下方操作放在同一组中，间距随错误一起收起，隐藏后不留下额外空白。
- 首次进入已有错误、恢复缓存时直接显示；文字替换淡化过渡，滚动回到已有错误不重播入场。
- `ReadLayout` 协调父容器高度动画，避免父容器再次追逐错误展开过程。
- 跟随系统动画倍率；关闭动画时直接更新到最终状态。

登录、修改查询密码、挂失/解挂、代人充值、充值金额、缴费支付密码、头像、房间管理和使用说明采用共享组件；账单、统计、大厅和“我的”的局部读取提示也采用相同动效。

整块读取失败继续由 `ReadUnavailable` 的内容切换控制；账单底部的固定高度反馈继续由原有 `ContentFade` 控制。

## 位置

表单内联错误统一放在最后一个输入框下方，保持多个输入框连续。登录、修改密码、收款人查询、金额输入和账单筛选均遵循这一规则；不同错误类型使用同一提示位置。

## 清除规则

| 界面 | 实际修改时清除 | 保留的提示 |
| --- | --- | --- |
| 登录 | 学号或密码变更清除凭据拒绝 | 网络错误、图形验证要求、会话错误 |
| 修改查询密码 | 原密码错误只由原密码变更清除；两次新密码不一致由新密码或确认密码变更清除 | 未确认的提交结果、未知服务端错误 |
| 挂失/解挂 | 查询密码变更清除已确认的密码拒绝 | 网络、会话和操作结果待确认 |
| 代人充值查询 | 收款信息变更清除收款信息错误并重置查询结果；验证码变更只清除验证码错误 | 会话和未知服务错误；编辑验证码不刷新图片或重新查询 |
| 卡片充值、代人充值、缴费金额 | 金额变更清除对应金额拒绝；本地金额校验在失焦时重新显示 | 网络、账户失效、未知服务端错误 |
| 缴费支付密码 | 密码或支付账户变更清除密码拒绝，保留现有订单和支付准备 | 其他支付失败、结果待确认 |
| 账单、统计、大厅、“我的”的读取提示 | 读取成功或明确重试由原有读取状态更新 | 无关输入不清除读取错误 |
| 头像、房间管理、使用说明 | 由原有选择、重试、保存流程更新 | 没有相关输入时不新增清除行为 |

“实际修改”比较过滤、长度限制后的有效值。只聚焦、切换密码可见性、输入被过滤的字符或提交后程序清空密码，不触发输入错误清除。

金额校验进入编辑态时暂时隐藏，失焦后按当前值重新判断；金额无效时提交按钮始终禁用。消失动效短暂保留旧提示文字，不代表错误状态仍有效。

## 错误归属

`FormField` 和 `ScopedInputError` 表达错误对应的字段，不按错误文案猜测。已知协议密码拒绝码 `60005`、验证码拒绝码 `8002/8003`、收款账户查询拒绝、凭据拒绝和本地输入校验有明确归属。

无法确认字段归属的远端业务错误不自动清除，避免修改无关输入后隐藏仍然有效的失败提示。后续接入明确协议码时再增加对应字段归属。

## 验证

专用 UI 测试覆盖显示与隐藏的几何变化、父容器协调、首次已有错误、错误文字替换、快速反复更新、缓存恢复、关闭动画，以及登录、验证码、金额的实际编辑行为。ViewModel 和协议测试覆盖错误归属、保留未知失败，以及编辑不会再次发请求或丢失订单。
