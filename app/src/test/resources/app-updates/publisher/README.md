# Python publisher interoperability fixture

These public-only fixtures were generated by `scripts/publish_app_update.py`
against a minified local APK on 2026-11-12. The check used real Android Build
Tools 37.0.0 and a temporary APK certificate, while replacing network calls and
publishing into temporary local Git repositories.

`latest.json` is the publisher's signed pointer; `manifest.json` is its signed
manifest; `public-key.txt` is the matching Ed25519 public key. No private keys
or installable APK are included. The repository and CDN URLs identify test
fixtures and are intercepted by the Android test.

`AppUpdateApiTest.pythonPublisherOutputResolvesInAndroidAndSurvivesVerifiedCacheRestoration`
checks the actual Python serialization, pointer digest, Ed25519 signatures,
beta/stable fallback, version fields and verified cache restoration in Android.
The test clock is tied to the fixture publication time so the signed expiry
does not cause the test to fail as calendar time advances.
